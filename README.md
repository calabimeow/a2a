# a2a
Image to ASCII converter written in Assembly

<img width="1318" height="702" alt="a2a_preview" src="https://github.com/user-attachments/assets/cf4416d1-3746-4fd9-9b8c-94cbed6677bb" />

### How to use
Write `a2a filename.ppm scale_factor` in your console

ppm P6 is the only supported format for now

scale_factor controls the size of the output ASCII art, higher values make the output smaller

For example:
`a2a img.ppm 4`

**Note**: this program is made for Windows. Don't expect it to run on your machine
